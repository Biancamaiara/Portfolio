## 🧠 Technologies Used

This project was developed with the following stacks and libraries:

| Technology | Description |
|-------------|------------|
| ⚛️ **React** | Main library for building the interface |
| 🎨 **TailwindCSS** | CSS framework for fast and responsive styling |
| 🧩 **React Slick** | Carousel used in the *Skills* section |
| 🪄 **Lucide Icons / React Icons** | Beautiful and consistent vector icons |
| 🌀 **Framer Motion** | Smooth and modern animations |
| 🌐 **Vite** | Fast and optimized build tool |

## 🧑‍🎨 Design and style

The design focuses on minimalism, soft contrast, and full responsiveness, leveraging the power of TailwindCSS.
Animations and interactions have been carefully implemented to create a fluid, modern experience with a touch of neomorphism.
